# VibeKits dev.154 应用中心验收记录

## 目标与交互位置

- Windows 与 macOS 共用同一套 Flutter 页面和交互逻辑。
- 一级导航顺序固定为“开发工具 → 应用中心 → 关于我们”。
- macOS 只请求并展示 `os=macos`，Windows 只请求并展示 `os=windows`。
- 页面支持分类、关键词搜索、刷新、应用卡片和详情；不替换 Harness 插件市场，二者职责独立。

## 市场接口契约

- 分类：`GET https://kemi.newlinksz.com/kd-api/api/store/categories`。
- 应用：`GET https://kemi.newlinksz.com/kd-api/api/store/apps?page=1&pageSize=100&os={macos|windows}`。
- 客户端不只信任查询参数，还会使用返回条目的 `os_type` 或 `platforms` 二次过滤。缺少明确平台归属的条目不展示。
- 安装只接受 HTTPS；macOS 后缀限定为 DMG、PKG、ZIP，Windows 限定为 EXE、MSI、ZIP。下载字节数必须与市场声明完全一致，SHA-256 必须为 64 位小写十六进制且实算一致，失败时删除临时文件并禁止打开。
- 市场条目缺少 HTTPS、精确大小或 SHA-256 时仍可查看说明，但安装按钮禁用。
