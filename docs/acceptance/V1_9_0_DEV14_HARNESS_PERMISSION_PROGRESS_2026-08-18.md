# Vibekits 1.9.0-dev.14 Harness 权限与中间态验收

日期：2026-08-18

平台：Windows x64

## 产品结果

- 权限菜单改为“请求批准 / 帮我批准 / 完全访问权限”。
- 默认使用“帮我批准”：已注册、非破坏性的工具自动执行，仅破坏性操作询问。
- 用户选择跨重启保存，不再每次启动恢复为频繁询问。
- “完全访问权限”不弹工具确认，但只能使用 APP 注册工具；ADB 禁止命令、参数限制和目标锁定继续生效。
- 权限菜单从底部输入框向上展开，避免副标题菜单项被屏幕边缘裁切。
- 回复中间态可展开显示理解任务、规划、工具名称与目标、执行成功/失败、耗时、继续分析和生成回复。
- 展示的是可核对的推理摘要与动作证据，不泄露模型私有逐字思维链。
