# Vibekits v1.7.0 文件搜索与响应性验收

日期：2026-08-17
版本：`1.7.0+9`

## 用户路径

1. 进入“开发工具 → 文件搜索”。
2. 选择目录，输入关键词，按 Enter。
3. 结果可定位、复制路径或一键计算 SHA-256。

类型、最小大小、修改时间、隐藏项和递归位于折叠筛选；默认界面不展示低频参数。

## 线程合同

- UI Isolate 不执行目录递归、完整文件哈希、压缩解码/编码或批量文件改名。
- 清理目标发现、扫描和删除全部位于工作 Isolate。
- 文件搜索、文件哈希、重复文件扫描和删除位于工作 Isolate。
- 批量重命名的规划与执行、纯 Dart 压缩包读取与创建位于工作 Isolate。
- 进度事件约 100 ms 限频；取消通过独立 SendPort 转发。
- 工作区销毁立即发出取消，不等待扫描完成才能释放界面。

## 边界

- 操作系统级磁盘拥塞仍可能降低所有进程的 I/O 速度，因此扫描器保持顺序读取、结果上限和 I/O 让步；线程隔离保证窗口消息泵不被 Dart 扫描逻辑占用。
- 文件搜索结果转压缩和批处理仍待接入；当前完成定位、复制和 SHA-256。
- macOS Release 和响应性仍需 Apple Silicon/Intel 实机复核。
