# v1.9.0-dev.71 Clash Verge 工作区验收

## 验收目标

“Clash Verge”必须能在 Vibekits 内完成一次真实代理工作流，不能只是启动外部进程的入口：添加配置、启动、切换系统代理、读取节点、选择节点、查看状态、停止并恢复网络。

## 已完成行为

1. 支持粘贴 HTTPS 订阅地址以及导入 `.yaml/.yml`；订阅地址进入系统凭据库，配置清单不保存 token。
2. 配置列表和当前选择本地持久化；订阅支持手动更新和删除。
3. Release 内置 Mihomo 读取所选配置；控制端口强制为 `127.0.0.1/localhost`，未配置时自动分配。
4. 运行页读取 Mihomo `/configs`、`/proxies` 和 `/connections`，显示真实模式、节点组、活动连接、上传/下载总量和进程日志。
5. 支持规则、全局、直连切换，以及每个 Selector 代理组的节点选择。
6. Windows 系统代理可开关；停止或启动失败均恢复原设置。App 退出时沿用统一进程树生命周期关闭 Mihomo。
7. 宽屏为配置侧栏 + 控制台，窄屏为单滚动区，无嵌套无界 Flex。

## 人工验收步骤

1. 打开“开发工具 → Clash Verge / 虚拟机 → Clash Verge”。
2. 点“添加订阅”并粘贴订阅地址，或点文件按钮导入 Clash YAML。
3. 选中配置，点“启动代理”，确认 Windows 系统代理切换。
4. 在“代理模式”切换规则/全局/直连；在“代理组与节点”选择节点，确认当前节点和流量数据刷新。
5. 查看“运行日志”，点“停止”，确认原 Windows 网络设置恢复。

任何一步出现假数据、无法选择节点、停止后代理未恢复或页面卡死，均判定失败。
