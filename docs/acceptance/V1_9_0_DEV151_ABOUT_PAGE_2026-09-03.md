## 实现与跨平台

- “关于我们”是“开发工具”之后的第六个一级入口，桌面侧栏、紧凑顶部导航和移动导航从同一标题、图标和页面数组生成。
- Windows、macOS、Linux 和移动端共用 `AboutTab`；没有新增平台分叉。`Ctrl+6` / `Cmd+6` 与点击进入同一页面。
- 页面最大宽度 1080px、左右 24px；正式图标为 64×64、16px 圆角；产品区为 16:9；能力卡在 760px 以上两列、以下一列。
- 页面完全复用 VibeKits 的 `VibekitsPalette`、Material 主题、圆角、边框和明暗模式，不硬编码 KEMI 蓝。
- 因没有独立资源接口，本版没有网络请求、轮播或缓存计时器，不会阻塞首窗或产生离页泄漏。将来增加在线资源时，必须单独实现 HTTPS 白名单、摘要/大小/解码校验、active/backup 双指针和原子发布后才能启用。
- 应用版本、LMCP `appVersion` 与 `catalogRevision=2151` 同步，避免 UI 与局域网设备目录显示不同版本。
