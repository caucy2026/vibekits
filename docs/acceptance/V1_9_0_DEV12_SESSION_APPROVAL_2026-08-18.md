# v1.9.0-dev.12 Harness 会话授权验收

日期：2026-08-18

平台：Windows x64
源码版本：`1.9.0-dev.12+22`

- Harness 输入框增加权限菜单，默认“首次询问”，可切换为“每次询问”并随时清除本会话授权。
- 风险操作弹窗提供“拒绝”“允许一次”“本会话允许同类操作”。
- 会话授权键由工具 ID、明确目标和命令范围组成。ADB 参数按前两个参数区分，例如 `shell getprop`、`shell dumpsys`、`install` 不互相继承权限。
- 新建会话、切换工作区和退出 APP 会清除授权；授权不会写入磁盘，也不会跨重启继承。
- 同一设备的第二次 `shell getprop` 自动通过，不再弹窗；定向 Widget 测试 1/1 通过。
- 同时修复 800px 测试窗口下长工作区名称导致 Harness 顶栏溢出的问题。
