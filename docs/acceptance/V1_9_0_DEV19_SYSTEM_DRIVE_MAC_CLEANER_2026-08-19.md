# Vibekits 1.9.0-dev.19 系统盘与 macOS 清理验收

版本：`1.9.0-dev.19+29`

## 验收范围

- Windows 系统盘标准目录、其他根目录和根文件的递归容量分析。
- 总量、已用、剩余、已归类、未归类/不可读空间总结。
- 全部根项目的占用来源、合理性、判断原因和统计完整性 JSON 报告。
- Windows 规则库 v3 的系统盘根目录大型诊断文件与 `C:\estlog` 旧日志候选。
- macOS 清理规则库 v1 的 26 条明确缓存/日志规则。
- 扫描、空间分析与删除均不阻塞 UI，并支持取消。

## 自动证据

- `flutter analyze`：0 问题。
- 合并回归：27/27 通过，覆盖界面容量总结、独立 Isolate 进度/取消、真实字节计量、标准/未知分类、深度/大小/年龄过滤、`estlog` 新旧文件过滤和完整 JSON 报告。
- Windows Debug 构建：待本批次构建完成后记录。

## 安全边界

- 系统盘分析为只读操作，不读取文件正文，不删除任何内容。
- 未知根目录只标记“需复核”，不得自动删除。
- 根目录通用诊断文件与 `C:\estlog` 规则默认不选；仅列出达到年龄/大小约束的候选，由用户确认并优先进入回收站。
- 链接和目录联接不跟随；不可读目录与达到枚举上限的目录明确标记，容量显示为下限值。

## 尚需实机证据

- 在实际 Windows 系统盘完成一次只读分析，核对权限目录、总耗时和其他应用并发响应。
- 在用户确认候选后执行实际清理前后容量对比；本批自动测试没有删除用户文件。
- macOS arm64/x64 构建、废纸篓和真实缓存目录验证。
