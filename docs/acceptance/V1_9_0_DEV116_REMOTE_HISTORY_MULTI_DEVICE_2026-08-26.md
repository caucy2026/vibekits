# v1.9.0-dev.116 远程历史、自动凭据与多设备验收

## 用户闭环

1. 首次连接填写主机、用户、端口和密码，并确认真实主机指纹。
2. 认证成功即自动建立“用户@主机:端口”历史，不再要求另点一次“保存会话”。
3. 再次启动 APP，从“最近会话”选择设备并点击连接；账号和密码由记录和系统凭据复用。
4. 已连接时点击“新建终端”，可选择另一历史设备或新设备，原终端不断开。
5. Harness 调用 `vibekits.remote.list_profiles` 可看到历史、在线状态和并行连接数，后续 SSH/SFTP 调用继续用 `profileId` 复用系统凭据。

## 安全边界

- 普通设置只保存非敏感资料、最近使用时间和主机指纹。
- 密码只进入平台安全凭据库，不进入 JSON、Harness 结果或工具日志。
- Harness 只得到 `profileId`、主机元数据、主机指纹是否已绑定和在线状态。
- 主机指纹变化不会自动放行。
