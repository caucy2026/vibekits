# v1.9.0-dev.83 全工具智能体闭环验收

## 本轮补齐

- 新增 `vibekits.system.capability_check`，Harness 可自行核对所有公开工具是否有真实本地处理器，并看到被安全隐藏的能力及原因。
- 发布合同从“每个工作区至少一个工具”升级为“每个公开工具都必须有处理器”。
- 30 个常用微工具从单一代表调用升级为 30/30 逐项 Harness 真调用、真实结果断言和逐项日志断言。
- 系统资源 PowerShell 探针改为可取消进程；资源页销毁或 APP 退出时终止探针，不遗留 25 秒计时器或后台进程。
- 点击性能测试为资源页注入确定性快照，测试 UI 响应而不是让系统探针污染交互计时。
