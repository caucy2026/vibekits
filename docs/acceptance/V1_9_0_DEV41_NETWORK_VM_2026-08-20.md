# Vibekits 1.9.0-dev.41 网络代理与轻量虚拟机验收

## 实现范围

- 开发工具新增“网络与虚拟化”融合入口，右侧为 Clash Verge 与轻量虚拟机两个 Tab。
- Windows 发布包内置 Mihomo Meta 1.19.29 和 QEMU 11.1.0 x86_64 最小子集，不依赖 PATH、另装 Clash/QEMU 或运行时下载。
- Harness 注册运行时检查、状态、代理启停、虚拟机启停六项结构化工具；继续复用全局/模块日志和权限系统。
- Mihomo/QEMU 均为独立子进程，参数以列表传递且 `runInShell=false`；QEMU 不开放任意参数拼接。
