# v1.9.0-dev.34 Harness 工具闭环验收报告

日期：2026-08-19  
平台：Windows x64  
版本：`1.9.0-dev.34+44`

## 1. 本轮交付

- 保存的 SSH/SFTP 会话可被 Harness 列出和调用：SSH 命令、SFTP 列表、上传、下载。
- 保存的 PostgreSQL、MySQL、MariaDB 会话可被 Harness 列出、检查对象和执行只读 SQL。
- 文件哈希、重复文件扫描和磁盘占用分析移入后台 Isolate，Harness 调用不占用 Flutter UI Isolate。
- 所有工具统一写入 Harness 审计记录；记录不包含密码或私钥，可沿用现有逐条删除、全部清空和关闭记录开关。
- 开发工具左侧每个入口由自动合同测试保证至少存在一个 Harness 可执行适配器。

## 2. 安全和操作合同

| 项目 | 结果 |
|---|---|
| 凭据 | 只从 Windows Credential Manager/macOS Keychain 读取，不进入工具参数或返回值 |
| SSH 主机 | 仅允许已经手工确认并保存指纹的会话，类型与指纹必须同时匹配 |
| 数据库 | 仅允许读取类 SQL，最多 500 行，写入/管理关键字拒绝 |
| 文件扫描 | 后台 Isolate；重复文件只给出建议，不自动删除 |
| 磁盘分析 | 后台 Isolate；只读返回总量、已用、剩余、归属与合理性，不自动删除 |
| 审批 | 只读能力直接运行；设备控制、上传下载和远程连接按当前 Harness 权限模式审批 |
| 审计 | 成功、失败、拒绝均写真实工具记录；ADB 继续由真实 `adb.exe` 服务层落日志 |

## 4. 未伪报为完成的实证

- 本轮没有可控 SSH/SFTP 服务器，1 GiB 传输取消、断网恢复和远端哈希仍按 E-08 补证。
- 本轮没有 PostgreSQL/MySQL/MariaDB 测试服务，TLS/错误凭据/慢查询停止仍按 E-02 补证。
- 本轮没有 Android 真机或物理串口，ADB 与串口硬件证据仍按 E-07/E-01 补证。
- 当前机器不是 macOS，macOS Release、Keychain 和硬件路径仍按 E-06 补证。
- 文档、压缩、OCR、截图和系统清理属于 App 主工作区，不等同于“开发工具左侧入口”；本轮只为磁盘占用分析增加 Harness 只读工具，其他主工作区的细粒度 Harness API 仍需后续按安全合同逐项开放。
