# v1.9.0-dev.115 SFTP 双栏目录导航验收

## 现场问题

SSH 认证后的 SFTP 已能同时显示本地和远端文件，但进入子目录后没有快捷返回路径，不符合主流双栏文件管理器的操作习惯。

## 实现合同

- 本地和远端各自提供“后退”和“上一级”按钮。
- “后退”返回该面板上一个实际访问过的目录；“上一级”返回当前路径的父目录。
- 两侧历史栈完全独立，本地导航不改变远端历史，反之亦然。
- Windows 磁盘根和远端 `/` 禁用“上一级”；无历史时禁用“后退”。
- 路径输入框回车进入目录时同样记录历史，失败时恢复原路径。
