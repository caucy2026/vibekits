# v1.9.0-dev.60 实际释放与半年未使用建议验收

## 验收边界

- 扫描与磁盘分析是只读操作，不删除用户数据。
- APP 只对可再生成且规则明确的缓存给出安全推荐；需确认项目、回收站、下载和重复文件保持独立语义。
- “达到 10 GiB”只以清理前后目标磁盘可用空间的真实增量为准，候选大小和移入回收站大小均不算实际释放。

## 已关闭问题

1. 移入回收站不再增加 `releasedBytes`，而是单独进入 `recycledBytes`。
2. 回收站候选强制最后执行，清空成功后才把其中容量计入释放。
3. UI 使用磁盘容量前后差作为最终释放值；若空间未增加，会显示“尚未释放”，不会增加累计值。
4. 智能计划展示安全项、需确认项和永久清空回收站开关，并实时计算是否达到 10 GiB；下载和重复文件排除在自动计划外。
5. 半年未使用建议只依据 Windows Prefetch 最后启动时间；无证据显示“无法判断”。软件条目显示安装路径并提供系统注册的正式卸载入口。

- `cleanup_deleter_report_test.dart`：覆盖永久删除、回收站容量分账、失败/跳过/取消和报告版本 3。

## 人工验收步骤

1. 打开“系统清理”，先点“分析全部磁盘占用”；UI 应立即出现，软件信息随后合并。
2. 点“扫描可清理项”后进入智能计划，核对三级容量和 10 GiB 差额。
3. 只选择理解且同意的项目；需要真实释放时必须明确勾选“永久清空系统回收站”。
4. 清理结束核对“实际释放”和系统盘当前可用空间。两者必须来自磁盘增量；若文件仅被移入回收站，应显示尚未释放。
5. 进入“半年未使用软件”，核对证据、安装路径；卸载按钮必须启动该软件自己的正式卸载器，由用户继续确认。

本版本不宣称已经在用户机器上实际永久删除 10 GiB；只有用户执行后的磁盘增量达到目标，APP 才显示验收通过。
