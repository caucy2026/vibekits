## 安全边界

- 自动测试只操作测试创建的临时沙箱，没有删除真实用户文件。
- Downloads、Windows.old、驱动包、Prefetch 和注册表不在直接删除规则库。
- Windows Update、传递优化和待上报 WER 等系统托管内容默认不勾选；后续优先改用系统清理 API。
- 本轮不宣称达到“比 360 更智能”的最终目标；真实 Windows 7/10/11 样本、常用软件版本矩阵和与其他应用并发时的磁盘/响应曲线仍需持续验收。
