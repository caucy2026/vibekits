## 工具补齐

- `vibekits.git.list_remote_refs`：使用随 APP 打包的 MinGit 执行有界只读 `ls-remote`。
- `vibekits.git.read_remote_file`：浅取明确 ref 到 APP 临时目录，只返回一个最大 2 MiB 的文本文件，随后删除临时对象。
- `vibekits.git.clone_minimal`：只克隆明确的单仓库、ref 和深度；目标目录必须不存在，失败自动清理本次创建的残留。
- 网络 Git 禁止隐藏凭据交互；URL 禁止明文密码，仓库内文件路径禁止绝对路径和 `..` 越界。
