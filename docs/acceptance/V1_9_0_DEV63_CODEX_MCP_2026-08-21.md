# v1.9.0-dev.63 外部 Codex MCP 闭环验收

日期：2026-08-21

## 目标

解决外部 Codex 会话只有接口文档、没有 `vibekits.windows_node.*` MCP 工具且缺少启动命令的问题。

## 实现

- VibeKits APP 启动即发布 `127.0.0.1` 随机端口与 256 位随机 token 的短期 connection file，退出时只删除属于本进程的文件。
- 新增 `tool/start_vibekits_mcp.ps1`，使用 Release 内置 Node/MCP；APP 未运行时自动启动并等待 bridge，不执行 npm/npx 下载。
- 新增仓库级 `.codex/config.toml`，并通过 Codex 内置 CLI 写入用户级 `mcp_servers.vibekits`。
- 外部调用复用 `vibekits.tools.v1`、领域服务和活动日志；写入类调用回到 APP 逐次批准。
