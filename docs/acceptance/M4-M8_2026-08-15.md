## 已知限制（诚实标注）

1. **rar / iso 解压**：7za 不内置 rar 解压与 iso 挂载，需引入 unrar 或 7z 完整版（含 7z.dll），界面明确提示。
2. **GB18030 / Big5 编码**：✅ 已解决（`NativeCodec` kernel32 `MultiByteToWideChar` FFI，cp 54936/950）。
3. **OCR / ASR / TTS 推理**：运行时（ONNX Runtime / sherpa-onnx）与模型文件需外部下载，当前为管理 + 工作区框架，非伪成功。
4. **大文件流式读取**：✅ 已解决（`FileLineIndex` 流式行索引，>64MB 文本按需读行）；拖放、文件关联待后续迭代。
