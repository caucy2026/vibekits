## 根因和修复
官方 SessionNodeItem 将 ID 放在组件 node.id 中，没有输出原注入逻辑所需的 DOM ID 属性或链接。旧逻辑得到空 ID 后，按标题在工作区索引里解析；未分组会话不在该索引，同名标题也不能可靠定位。
注入层改为读取被点击行关联的 node.id（搜索结果使用 result.id），限定会话 ID 格式。精确 ID 存在时禁止按同名标题匹配其他行。官方 Harness 依赖未修改。
