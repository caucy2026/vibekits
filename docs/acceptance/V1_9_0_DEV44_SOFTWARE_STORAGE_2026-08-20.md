## 用户可见结果

- 点击“空间分析”后默认进入“软件占用与操作”，逐个软件显示：安装体积、软件数据、可清缓存、合计占用和正常/偏大/需复核/优先处理。
- 列表支持软件名与发布者搜索；Windows 未提供体积且磁盘扫描未关联到路径时明确显示“体积未知”，不虚报为 0 B。
- “清理缓存”只处理扫描得到且允许回收的精确 Cache/Logs 目录，二次确认后进入系统回收站；配置、数据库、下载和用户文件不进入该动作。
- “卸载”只启动 Windows 注册表登记的厂商或 MSI 卸载器，不直接删除 `Program Files`。
- “系统占用与异常”展示物理总量/已用/剩余、空间压力、Windows 系统逻辑量基线、分类总量和异常项目数；每项给出判断依据与建议动作。

## 数据关联

| 数据源 | 用途 | 执行方式 |
|---|---|---|
| HKLM 64 位卸载注册表 | 名称、发布者、版本、安装位置、估算体积、卸载器 | 与其他视图并行子进程读取 |
| HKLM WOW6432Node | 32 位软件信息 | 与其他视图并行子进程读取 |
| HKCU 卸载注册表 | 当前用户安装的软件 | 与其他视图并行子进程读取 |
| Program Files / Program Files (x86) | 实际安装目录逻辑量 | 系统盘分析 Isolate，3 个有界工作线程 |
| ProgramData / Users/*/AppData | 软件共享数据和用户数据 | 同一分析 Isolate |
| Cache/Logs 等精确后代目录 | 可再生缓存大小和安全清理路径 | 同一遍扫描生成，不重复全盘扫描 |

软件归属优先按规范化安装路径匹配，再按软件/目录名称匹配；Microsoft、Google、Adobe 等通用厂商目录不会强行归给某一个产品。

## 异常判断

- 系统盘剩余 `<5%`：优先处理；`<10%`：需复核；`<20%`：偏大/需关注。
- Windows 系统目录常见逻辑量启发式为 20–40 GiB；超过 40 GiB 提醒关注，超过 60 GiB 提醒复核，但始终禁止手工删除系统目录。
- 单软件缓存/日志 `>=1 GiB` 需复核，`>=5 GiB` 优先处理。
- 单软件数据 `>=10 GiB` 需复核；安装体积 `>=20 GiB` 提醒不用时通过卸载器移除。
- NTFS 硬链接产生的逻辑量重复计数会单独说明，不把目录逻辑量错误当成物理占用相加。

## 安全边界

- 扫描本身只读，可取消，不在 UI 线程执行全盘遍历。
- 缓存清理需要用户确认，默认进入回收站。
- 软件卸载需要用户确认，由软件自身卸载器继续交互。
- Windows、Program Files、恢复、分页、休眠、用户文档和无法明确归类的数据不会被软件缓存按钮直接删除。
