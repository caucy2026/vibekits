# v1.9.0-dev.65 30 项高频微工具验收报告

日期：2026-08-22
版本：`1.9.0-dev.65+75`

## 1. 目标与结论

在不扩大左侧导航、不增加联网依赖和不复制第三方源码的前提下，对照 GitHub 高采用度开发工具补齐 30 项常用能力。每项必须同时从统一界面和 Harness 调用，并由开发工具模块记录真实调用证据。

结论：30 项均已注册、可执行、可由 Harness 发现和调用；代表输入 30/30 通过。所有能力为离线只读微操作，输入上限 1 MiB，不修改文件或系统状态。

## 2. GitHub 调研与去重

| 上游 | 吸收内容 | 未采用内容 |
|---|---|---|
| DevToys | 分类、智能到达、常用转换器任务版图 | 不复制 Fluent UI，不增加同类独立页面 |
| CyberChef | 离线、可组合、输入验证和有界执行 | 不引入整个 Web 应用或任意 recipe 执行器 |
| Hexkit | JWT、chmod、颜色、CSV、Query、文本等缺口清单 | 不复制仓库代码、品牌或布局 |

现有 Base64、URL/HTML/Unicode/Hex、哈希/HMAC/UUID、JSON/YAML/TOML/XML 查询、正则、CIDR/DNS/TCP、文件搜索/Diff/哈希、Git/SSH/ADB 等均保留并去重，没有为了数量重复实现。

## 4. 融合闭环

```text
ToolSpec（单一能力清单）
  ├─ 开发工具 → 转换与检查 → 分类 Tab/横向工具条
  ├─ Harness tools/list：自动得到 vibekits.<id>
  ├─ Harness invoke：复用同一个领域处理器
  └─ 当前工具 Harness 记录：复用统一活动日志，可关闭或删除
```

30 项没有成为左侧 30 个入口。用户在同一输入、参数、输出区切换；Harness 根据 ToolSpec 的名称、描述、使用/避免场景和参数合同自动选择。

## 6. 安全边界

- JWT 只解码，明确标记签名未验证；不能据此建立身份或授权结论。
- 所有输入在领域层限制为 1 MiB；不联网、不读取文件、不写文件、不执行 shell。
- 本批没有引入第三方源码、二进制或新增运行时依赖。
- 真实日志由 Harness bridge 在调用领域处理器时写入，聊天层不能伪造记录。
