# v1.9.0-dev.75 Clash 标准界面验收

## 本轮目标

- 保留 Vibekits 完整工具搜索列表；Clash 的内部导航只作用于自身工作区，不能隐藏或删除其他工具。
- 内部导航按 Clash Verge 常用顺序固定为：首页、代理、订阅、连接、规则、日志、测试、设置。
- 左栏底部展示来自 Mihomo 控制器的实时上传、下载速率和连接数。
- 代理页以代理组卡片组织内容；展开后采用双列节点卡片。
- 点击节点卡片直接切换；每个节点可单独测速；每个代理组及全部节点均可测速。
- 当前节点高亮，延迟按绿色、橙色、红色区分，超时明确显示。
- 虚拟机入口保留在设置页，不与代理主流程争抢一级空间。
- Mihomo 本地核心在已有配置时自动加载；节点管理、订阅、测速与设置不要求先启用 Windows 系统代理。
- “启用/关闭系统代理”只控制系统流量接管，关闭后本地核心继续服务界面和 Harness。

## 闭环检查

1. Flutter 静态分析：通过。
2. Mihomo 控制器延迟接口单元测试：通过。
3. Windows Release 构建：通过。
4. 发布版本：`v1.9.0-dev.75+85`。

本轮不伪造测速或流量数据：节点延迟来自 Mihomo `/proxies/{name}/delay`，流量和连接数来自 `/connections`。
