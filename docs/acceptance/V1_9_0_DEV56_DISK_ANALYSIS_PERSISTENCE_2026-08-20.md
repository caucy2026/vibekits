# v1.9.0-dev.56 磁盘分析明细与持久化验收

日期：2026-08-20

## 已实现

1. 软件列表点击后显示总占用、安装文件、软件数据、可清缓存、状态、判断、发布者、版本、注册表标识及所有关联路径。
2. 磁盘目录点击后显示完整路径、上级路径、精确字节数、分类、归属、修改时间、统计完整性、删除策略、识别依据和建议。
3. 磁盘目录列表取消前 40 项截断，使用惰性列表承载全部分析结果。
4. 最近一次多磁盘分析保存到 `%LOCALAPPDATA%\Vibekits\Reports\latest_drive_analysis.json`，JSON 编码和文件读写在独立 Isolate 中完成，并使用临时文件完成后再替换固定快照。
5. 再次进入清理页只读取本地快照，显示快照时间，不自动执行扫描；只有用户点击“分析全部占用”才重新计算。
6. 清理缓存和移入回收站不再隐式启动完整磁盘分析，避免用户点击后再次长时间等待。
