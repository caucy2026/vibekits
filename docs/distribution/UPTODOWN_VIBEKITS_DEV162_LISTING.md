## Full description

VibeKits brings an AI engineering workspace and a practical desktop toolkit into one macOS application. It keeps the official Harness project, conversation, draft, parallel-task, stop, permission, Skills, settings and plugin workflows while connecting them to native utilities.

Use local and authorized LAN MCP tools with visible execution steps, caller identity, permissions, activity logs, stop controls and result evidence. VibeKits can discover compatible MCP providers, inspect their published capabilities and select an available provider for a task without treating discovery as permission.

The built-in toolkit covers archive creation and extraction, safe cleanup planning, document and data viewing, hashes and encoding, time conversion, a hundredth-second stopwatch, network latency and bandwidth testing, ADB device work, serial communication, database access, audio utilities, Git and GitHub diagnostics, and other engineering calculations. File processing is local by default. Network and device actions remain subject to the app's permission and safety boundaries.

VibeKits supports Simplified Chinese, Traditional Chinese and English, light and dark themes, independent drafts for each conversation, parallel sessions, readable collapsible execution timelines, and background operation when the main window is closed. The Direct distribution package is Developer ID signed, Apple-notarized, supports macOS 12 or later, and contains both Intel and Apple silicon slices.
