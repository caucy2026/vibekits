# Vibekits 程序员一体化任务链

版本：1.0  
更新日期：2026-08-19  
目标：用一个工具完成程序员日常任务，而不是在多个孤立页面之间重复输入。

## 1. 联动合同

每条任务链统一为：自然语言或拖入输入 → 自动定位能力 → 必要的人机认证/审批 → 共享安全上下文 → 后台执行 → 结构化结果 → 就地下一步。

可跨工具传递：经过校验的文件路径、工作区、设备序列号、远程会话 ID、数据库会话 ID、串口参数、截图路径、文本结果和审计记录 ID。

禁止跨工具传递：密码、API Key、私钥正文、配对码、未脱敏请求头和其他秘密。需要认证时由目标工作区调用系统凭据或显示一次安全输入。

## 3. 高频能力缺口与取舍

不新增一级入口，按以下顺序补进现有工作区：

### P0：让现有工具真正协作

1. ADB 专用链：连接/配对、持续 Logcat、截图保存后直接 OCR、设备文件双栏、APK 安装结果回传。
2. 串口长会话：Harness 打开指定端口、共享当前端口句柄、发送/等待匹配、把有界 RX/TX 片段回传；关闭时释放原生句柄。
3. 统一结果动作：文件、文本、表格、日志、图片和 Diff 使用同一 `WorkflowArtifact`，提供适合类型的下一步而不是固定按钮集合。
4. 网络诊断：DNS、Ping/TCP、TLS 证书、代理、端口占用和 GitHub HTTPS/SSH 443 形成一次诊断报告并可恢复修改。
5. API 调试：环境变量、脱敏历史/集合、WebSocket；gRPC 只在能够随包提供稳定运行时后进入。

### P1：高频但需独立安全设计

- 进程/端口/日志工作台：端口→进程→日志→停止，结束进程必须明确确认。
- Redis 只读浏览与命令白名单；其他数据库不为凑数量加入。
- 测试运行器：识别项目后调用项目已有测试命令，输出与失败文件进入 Harness；不捆绑所有语言 SDK。
- 容器工作流：检测并调用已有 Docker/Podman Engine，不捆绑守护进程；容器日志/端口/文件与终端联动。
- 证书/JWT/二维码、文本/目录 Diff、Cron、颜色/时间等继续作为“转换与检查”微工具，不占左侧。

### 明确不做成重型孤岛

- 不内置一套新的 IDE、Docker Engine、Kubernetes 集群、完整 FTP 服务器或远程桌面协议栈。
- 远程文件默认使用加密的 SFTP；传统明文 FTP 不作为默认能力，FTPS 仅在真实需求和证书校验闭环后评估。
- 不为了“工具数量”复制低频项目；能力必须能进入至少一条完整任务链并复用统一审计、取消和结果模型。

## 4. 验收规则

- 同一秘密最多输入一次；相同会话优先复用系统凭据和已经确认的目标身份。
- 页面切换应立即发生，网络/磁盘/模型工作在后台；任何等待都显示真实状态并可取消。
- 每条链测试正常、拒绝、取消、错误、资源释放和敏感信息不落日志。
- Harness 返回必须是结构化真实结果；打开页面不冒充任务已经执行。
- 模拟测试只证明软件合同；真实 SSH、数据库、Android、串口和 macOS 继续按 E-01/E-02/E-06/E-07/E-08 补证。
