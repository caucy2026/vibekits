# Vibekits 统一验收矩阵

版本：0.1

平台：Windows/macOS

状态说明：`已通过` 必须同时有自动测试和对应平台 Release/人工证据；只有代码或设计时标记 `开发中`/`待实现`。

## 1. 全文件融合

| ID | 场景 | 完成标准 | 当前状态 |
|---|---|---|---|
| FUS-001 | 任意文件拖入 | 每一项得到专用能力、文本/Hex 回退或明确错误，不静默忽略 | Windows 已通过；macOS 待实现 |
| FUS-002 | 后缀伪装/未知 | 文件头和内容优先，显示真实识别依据，并允许当前会话覆盖 | 部分通过 |
| FUS-003 | 多文件/多启动参数 | 保留完整批次，逐项切换；相同能力可批量执行 | Windows 已通过；批量同能力待实现 |
| FUS-004 | 结果继续处理 | 常用下游动作就地可达，不要求保存后重新导入 | 待实现 |
| FUS-005 | 极简操作预算 | 拖入到只读结果 0～1 次点击，工作区只有一个主操作 | 部分通过 |
| FUS-006 | 系统入口 | Windows 右键/打开方式、macOS Finder/Open With 使用同一路由 | Windows 已通过；macOS 待实现 |
