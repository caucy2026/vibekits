# Harness 派生会话：四端产品需求与验收标准

更新：2026-09-23。来源：用户在 `Harness远程仿真.pad` 于 2026-09-19～20 的原始要求，以及 2026-09-23“四端都需要，先在 MAC 测试稳定后再验收”的指令。

## 产品要求

| ID | 必须满足的行为 | 禁止结果 |
|---|---|---|
| HC-01 | 从长会话整理、压缩上下文，创建独立派生会话继续开发 | 复制整段聊天时间线、只创建空壳 UI |
| HC-02 | 在创建时整理一次上下文并真实交接，随后独立继续任务 | 每条消息重新总结、没有交接却显示完成 |
| HC-03 | 点击后立即出现反馈，创建后先切入新会话，再在正文中显示整理动画 | 菜单卡死、长时间无反馈、总结完成才出现新会话 |
| HC-04 | 新会话拥有真实 ID，标题为“原名称 2、3……”，刷新/重启后保存 | 只有临时 DOM、同一次重试重复创建子会话 |
| HC-05 | 新会话知道来源，信息不足时可返回或受控查阅原会话记录 | 复制全部历史、按相似标题读取其他来源 |
| HC-06 | 整理进度及失败状态只属于来源和派生会话，第三会话可正常使用 | 全局等待、底部黑色提醒、状态串会话 |
| HC-07 | 等待有总超时，失败清楚可见并可重试，重试复用子会话 | 无限旋转、重试入口消失、DOM 忙循环、高 CPU 卡死 |
| HC-08 | 自增入口统一叫“派生会话”，保持官方布局，仅混入少量暖黄色 | 混叫“打开/继续/新会话”、重复菜单、纯蓝纯黄突兀样式 |
| HC-09 | 与官方 Harness 共存，不破坏旧会话、并发任务、草稿及删除行为；派生会话右键菜单保留重命名、分叉、归档、派生、删除各一项，点菜单外或按 Esc 可关闭，弹层不遮挡相邻内容 | 覆盖官方运行时、自动删除来源、误删其他会话、菜单只剩删除、重复或关不掉的菜单 |
| HC-10 | 四端实现同一功能合同，先 Mac 真实测试稳定再交用户 | 用单元测试、后台接口或一端通过冒充全部验收 |
| HC-11 | 派生会话在首次提问前能查看完整交接摘要；侧栏可删除派生会话且只作用于其真实 ID | 摘要仅隐式注入模型、空白界面无法查看、复制的侧栏按钮失效或误删来源 |

“九段摘要”“systemPrompt provider”“每轮复用同一摘要”属于实现方案，不冒充用户指定算法；是否达标以压缩、真实交接、一次整理和能继续开发为准。模型整理和本地整理均不得绕过失败恢复、来源边界及真实交接验证。

## 原话与后续覆盖

- 9 月 19 日：聊天记录不用继承；有问题时知道来源，能去原会话找对应记录；长会话不能直接复制影响性能。
- 9 月 20 日：“只在创建新会话时候做一次上下文总结 后续就没关系了”。
- 9 月 20 日：等待只在两个会话里，不能影响其他会话、不能全局等待、不能死循环退出不了；禁止 APP 下方黑色提醒。
- 9 月 20 日：早期“新会话”改为“派生会话”；自定义功能只混入少量暖黄色。
- 9 月 20 日：“马上出一个新的会话窗口然后在里面转圈处理的动画”，并要求删除和派生完整测试。

## 验收顺序与证据

先完成 macOS，再逐端记录 Windows、Android 及第四端的真实验收（第四端名称待与用户确认，不把缺失平台伪报为支持）。本轮不要求提前发布其他平台。

1. 冻结已签名 Mac 候选：版本、源码快照、包摘要、签名身份。
2. 正常流程：分组与未分组来源均能派生；新会话出现/选中、动画、独立 ID、标题、空历史、交接持久化、来源返回。
3. 实际首次任务能使用来源中的已知事实继续工作；原消息保持用户正文，后续不重复整理。
4. 连续三轮派生及第三会话切换，验证状态隔离；刷新及重启验证标题、关系和交接恢复。
5. 可控失败/超时验证错误可见、重试可点、复用同一子会话；保留首轮失败证据。
6. 有界 CPU/内存采样和挂起/崩溃检查；错误态及成功态都不得持续占满 WebContent CPU。前端不变状态重复渲染必须稳定，不产生自激 DOM 更新。
7. 删除回归只在隔离夹具验证，保留来源/子会话独立性，禁止借验收删除用户真实数据。

每项记录 PASS/FAIL/NOT RUN 及证据路径；任何必需项未通过都不交用户为“稳定版”。当前 dev227 初始候选派生为 BLOCK，详见 `acceptance/DEV227_CONTINUATION_AUDIT_2026-09-23.md`。

2026-09-23 后续：用户要求“做好后先给我测试”。Mac r3 已完成三轮真实派生、实际上下文问答、来源往返、第三会话隔离及重启恢复，作为本机试用候选交付；不是完整四端稳定版。具体证据及尚未覆盖的发布项见 `acceptance/DEV227_CONTINUATION_MAC_TRIAL_2026-09-23.md`。
