# 程序员工具版图与移植决策

版本：0.2
更新日期：2026-08-16

## 1. 信息架构决策

首页不按开源项目数量增加入口。每个高频问题只建设一个主工作区，相关微能力作为上下文动作、搜索命令或工作区内模式出现。

| 类别 | Vibekits 主工作区 | 首个范围 | 参考产品/标准 | 决策 |
|---|---|---|---|---|
| 计算 | 程序员计算器 | 进制、位宽、位运算、多进制结果 | Windows Calculator Programmer mode | 自研解析器和测试，不移植 UI |
| 数据库 | 数据库管理器 | SQLite 表/视图、分页、SQL、导入导出 | SQLite、DB Browser for SQLite、Outerbase Studio | 使用 SQLite 兼容库；只借鉴任务流，不复制 GPL UI/代码 |
| 源码 | 轻量源码工作区 | 常用语言、Shell、配置、查找、编辑、原子保存 | Zed、Geany、EditorConfig、语言标准 | 自研轻量编辑体验；不试图复制完整 IDE |
| 远程 | 远程连接 | SSH、SFTP、端口转发、会话资料 | OpenSSH、Tabby | 优先调用系统 OpenSSH；不自行实现密码学协议 |
| API | API 调试 | HTTP 方法、头、体、认证、响应查看 | HTTP 标准、Bruno/HTTPie | 自研有界客户端；本地保存且敏感值脱敏 |
| Git | Git 工作区 | 状态、Diff、日志、分支、安全提交 | Git 官方 CLI | 结构化调用 Git；危险写操作不自动执行 |
| 网络 | GitHub/网络诊断 | DNS、TLS、HTTPS、代理、SSH 22/443 | GitHub 官方连接文档、系统网络工具 | 不移植 MITM/证书替换；只做安全诊断和可恢复配置 |
| 转换/检查 | 通用转换 | 编码、格式、哈希、JWT/证书、二维码 | DevToys、CyberChef、IETF/RFC | 采用标准/许可清晰算法；按输入自动推荐 |
| 文件 | 文件工作区 | 哈希、重复、重命名、二进制、元数据 | 系统文件管理器惯例 | 复用统一文件身份和任务协议 |
| 压缩 | 压缩工作区 | 列表、测试、解压、创建 | 7-Zip/libarchive | 后端组合，统一安全和 UI 合同 |
| 本地智能 | 模型 | 截图 OCR | PaddleOCR、ONNX Runtime、Windows/macOS 系统截图 | 首屏只保留截图 OCR；固定模型和哈希，用户主动安装，无上传 |
| 智能代理 | 模型 | 项目选择、任务输入、流式结果、停止，后续 ACP | DeepSeek Harness 官方仓库/CLI | 固定官方 RC headless profile；Codex 风格应用内任务流，不复制快速变化的整仓源码 |
| 清理 | 清理工作区 | 开发/调试/下载/插件/应用缓存 | Windows/macOS 官方目录约定 | 自研白名单和快照；不使用激进“一键清理”规则 |

## 2. 移植边界

“移植”按以下优先级解释：

1. 优先采用开放标准、官方 CLI 或宽松许可的独立库。
2. 其次移植纯算法和标准测试向量，同时保留版权、上游提交和修改说明。
3. GPL/AGPL 项目只用于交互研究，除非完成单独许可证评审，不复制其源代码、资源或整体 UI。
4. 不把另一个工具整个嵌进 WebView，也不引入其遥测、账号、广告或云端依赖。
5. 每个新依赖记录用途、版本、许可证、平台产物和 SHA-256；能用系统成熟实现时不重复实现安全协议。

## 3. 体验统一规则

- 文件/目录可作为输入时必须支持拖放，自动填入并选择最佳模式。
- 首屏只有输入、一个主操作和结果；认证、编码、并发、代理等高级项按需展开。
- 最近使用和收藏用于“再次到达”，不能取代自动路由。
- 结果可复制、保存或转交下一工作区；同一文件不重复选择。
- 工具不可用时说明缺少的运行时/权限/平台能力，不显示伪结果。
- 长任务统一显示阶段、进度、取消；日志和历史默认脱敏。
