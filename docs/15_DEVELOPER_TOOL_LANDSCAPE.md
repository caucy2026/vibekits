## 2. 移植边界

“移植”按以下优先级解释：

1. 优先采用开放标准、官方 CLI 或宽松许可的独立库。
2. 其次移植纯算法和标准测试向量，同时保留版权、上游提交和修改说明。
3. GPL/AGPL 项目只用于交互研究，除非完成单独许可证评审，不复制其源代码、资源或整体 UI。
4. 不把另一个工具整个嵌进 WebView，也不引入其遥测、账号、广告或云端依赖。
5. 每个新依赖记录用途、版本、许可证、平台产物和 SHA-256；能用系统成熟实现时不重复实现安全协议。

## 3. 体验统一规则

- 文件/目录可作为输入时必须支持拖放，自动填入并选择最佳模式。
- 首屏只有输入、一个主操作和结果；认证、编码、并发、代理等高级项按需展开。
- 最近使用和收藏用于“再次到达”，不能取代自动路由。
- 结果可复制、保存或转交下一工作区；同一文件不重复选择。
- 工具不可用时说明缺少的运行时/权限/平台能力，不显示伪结果。
- 长任务统一显示阶段、进度、取消；日志和历史默认脱敏。

## 6. 2026-08-22 高频微工具补齐

本轮再次对照 DevToys、CyberChef 和 Hexkit。原则是补任务缺口而不是按仓库复制功能：已有 Base64、URL、哈希、JSON 格式化、正则测试、文件搜索、Diff、Git、SSH、ADB 等不重复建设；新增能力仍共享一个输入/结果区和分类 Tab。

| 分类 | 新增工具 |
|---|---|
| 格式/结构 | JSON 压缩、JSON 字符串转义/反转义、XML 格式化/压缩、CSV 转 JSON、JSON 转 CSV |
| 令牌/计算 | JWT 解码、JWT 过期检查、2～36 进制、字节序、字符码、chmod 编解码、SemVer 比较、容量/时间单位 |
| Web/颜色 | HEX 转 RGB、RGB 转 HEX、Query 解析/生成、HTTP 状态码、MIME 查询 |
| 文本/匹配 | 正则字面量转义、Glob 测试、行排序、行去重、文本统计、命名风格、换行符规范化 |

JWT 工具只解析公开载荷并明确返回 `signatureVerified=false`，不提供伪验证；全部操作限制 1 MiB 输入，不联网、不读取文件、不写回源数据。完整 ID 和测试证据见 `acceptance/V1_9_0_DEV65_UTILITY_PLUS_30_2026-08-22.md`。
