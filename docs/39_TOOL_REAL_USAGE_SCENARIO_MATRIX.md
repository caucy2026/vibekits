# 工具真实连续使用场景矩阵

## 最高验收规则

每个独立工具不能只验证“第一次能打开”。必须同时验证：首次完成任务、再次进入免重复配置、多个目标并存且状态不串、秘密进入系统安全存储、失败可取消/重试、Harness 读取同一份历史并留下真实工具日志。

运行时以 `vibekits.system.capability_check.productHierarchy.usageContracts` 为机器可读规则。新增独立工作区若没有 `ToolUsageContract`，合同测试直接失败。

## 本轮审查结果

| 工具 | 已具备的连续使用行为 | 本轮修复 | 后续仍需补齐 |
| --- | --- | --- | --- |
| 远程连接（SSH/SFTP） | 成功后保存主机/用户/端口/指纹；密码进系统凭据库；多终端并存；SSH 会话直接复用 SFTP | 纳入统一使用合同和 Harness 能力自检 | Android 与真实多服务器再做凭据迁移实测 |
| 数据库管理（SQL） | 多个远程配置并存；密码进系统凭据库；Harness 可列出历史并连接 | 明确 Android 可直接执行，不误判桌面工具 | 本地 SQLite 最近文件列表 |
| 网络代理（Clash Verge） | 多订阅、活动配置、节点选择和订阅凭据持久化 | 纳入统一使用合同 | 重启后系统代理状态恢复实测 |
| 串口调试（Serial） | 恢复端口、波特率、数据位、停止位、校验和流控；最近 50 条发送内容可复用 | 新增发送历史持久化，保存失败不阻断真实发送 | 多 USB 设备分别保存完整配置 |
| 接口调试（API） | 单次请求、取消、响应边界 | 新增最近 30 个请求；一键恢复；敏感头和正文不落盘 | 环境变量组、独立认证配置 |
| 网络抓包（PCAP） | 抓取、停止、保存、读取、分析及 Harness 接口 | 修复未进入独立工具列表的问题 | 最近 PCAP 与过滤器历史 |
| 安卓调试（ADB） | 多设备枚举、每条命令绑定序列号、Harness 真日志；最近 20 个无线地址与 50 条命令可复用 | 新增地址/命令持久化，保存失败不阻断连接和执行 | 给设备增加可编辑别名 |
| 版本控制（Git） | 仓库检查、Diff、备份预览/提交/推送 | 纳入统一使用合同 | 最近仓库与工作区切换记忆 |
| 网络诊断（GitHub） | 已确认代理可应用与回滚，Token 脱敏 | 纳入统一使用合同 | 保存最近诊断摘要 |
| 轻量虚拟机（QEMU） | 复用已有磁盘和镜像，可多实例 | 纳入统一使用合同 | VM 配置模板和最近实例列表 |
| 音频调试（PCM/WAV） | 当前文件参数、播放和分析在工作区保留 | 纳入统一使用合同 | 最近音频与多文件对比报告 |
| 资源诊断（CPU/GPU） | 本机/ADB 设备分目标采样 | 纳入统一使用合同 | 多次采样趋势和报告历史 |
| Diff/Hash/Search/Rename/Duplicate | 单任务内多文件、预览、取消和本地处理 | 纳入统一使用合同 | 最近目录/参数按工具分别持久化 |
| 程序员计算器/转换集合 | 当前工作区连续计算和跨工具复用输入 | 纳入统一使用合同 | 可选恢复上次非敏感输入 |

## 秘密保存红线

- SSH、数据库、订阅等密码只允许进入 Windows Credential Manager、macOS Keychain 或 Android Keystore。
- API 历史禁止保存请求正文、Authorization、Proxy-Authorization、Cookie、API Key、Token 或 Secret 类型请求头。
- Harness 工具日志记录目标、参数摘要、耗时和结果证据，不记录密码、密钥或文件正文。
