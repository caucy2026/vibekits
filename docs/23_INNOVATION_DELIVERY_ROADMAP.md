# Vibekits 融合式创新交付路线

更新：2026-08-20

## 1. 不可改变的方向

Vibekits 不是小工具宫格，而是本地优先的开发任务融合器：任意对象进入后自动识别，Harness 编排 App 内真实工具，结果直接进入下一步，每次执行都有可验证证据。

## 2. 创新项和交付状态

| 创新项 | 当前交付 | 下一验收边界 |
|---|---|---|
| 统一开发对象 | dev.40 已建立 12 类对象识别 | 连接安全句柄和跨页选中状态 |
| 智能下一步 | dev.40 已自动返回最多 3 个动作并进入 Harness | 在文档、ADB、SSH、日志结果区就地展示 |

## 3. 强制顺序

1. 先打通真实上下游和证据，再增加界面。
2. 先复用 `ToolSpec` 和领域服务，不为 Harness 另写行为。
3. 先完成一个高频场景的真实闭环，再扩展类型。
4. 任何远程能力默认脱敏、可停止、不降低工具原有权限。
