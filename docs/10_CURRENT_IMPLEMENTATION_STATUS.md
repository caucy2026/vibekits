# Vibekits 当前实现状态与未完成清单

更新日期：2026-08-16

当前版本：`1.3.0+4`

适用代码：本地 Windows 工程当前工作树

目标平台：Windows 优先，Android 平板后续

## 1. 文档口径

本文按当前代码、测试和可执行入口核对，不按计划表推定完成度。

- **已实现**：当前界面或领域服务已有可执行行为，并有自动测试或构建证据。
- **部分实现**：主路径可用，但产品规格中的格式、错误处理、进度、取消、安全或 UI 验收尚未完整覆盖。
- **未实现**：没有可执行入口、仍显示占位提示，或目标平台工程尚不存在。
- **未验收**：代码可能存在，但没有按 `04_WINDOWS_ACCEPTANCE_MATRIX.md` 和 `07_WINDOWS_UI_ACCEPTANCE_MATRIX.md` 完成 Release 实机证据。

因此，自动测试通过不等于“Windows V1 已全部完成”。当前产品定位应视为：**可运行的 Windows 工程预览版，五个模块已有主干能力，但正式发布闭环尚未完成**。

## 3. 应用外壳与通用能力

### 3.1 已实现

- Flutter/Dart 应用入口、浅色主题和五个一级 Tab。
- `Ctrl+1` 至 `Ctrl+5` 切换 Tab，`Ctrl+,` 打开设置对话框。
- Windows 窗口默认 1280×800，最小尺寸 1024×700，标题为 `Vibekits`。
- Tab 页面使用 `IndexedStack` 保留当前会话中的页面状态。
- Release EXE 在当前用户注册真实支持的文档、压缩与模型类型，出现在 Windows“打开方式/默认应用”中；任意文件右键可自动处理，外部多文件启动会逐项路由，不强制修改系统默认应用。
- `tool/register_file_types.dart` 可供安装阶段无界面注册指定 Release EXE；开发验证已确认 `.dart`、`.zip` 存在且 `.rar` 未被误注册。
- Windows Debug/Release 构建链已配置，Release EXE 曾完成本机启动验证。

### 3.2 部分实现或未实现

- 设置对话框已支持主题、日志级别、缓存上限、模型目录、解压条目/单文件上限和“恢复上次 Tab”，并原子写入 `%LOCALAPPDATA%\Vibekits\settings.json`；模型目录与解压限制已接入对应模块。语言切换仍未实现，日志级别和缓存上限目前仅完成持久化，尚未接入日志/缓存执行层。
- 用户设置损坏时会安全恢复默认值；最近文件仍未持久化。
- 后台任务面板没有完整任务调度、进度、取消、失败定位和关闭窗口保护闭环。
- 通用快捷键覆盖 Tab、设置及当前文档/压缩模块的 `Ctrl+O`，文档查找支持 `Ctrl+F`；`Ctrl+S/G/W/Tab` 等仍待统一。
- 150%/200% 缩放、1024×700 全流程以及多窗口状态尚未按 UI 矩阵人工验收。

## 4. T1 解压缩

### 4.1 已实现

- 格式路由：ZIP、TAR、TGZ/TAR.GZ、TBZ2/TAR.BZ2、TXZ/TAR.XZ、GZ、BZ2、XZ、7z；RAR/ISO 可识别但会明确提示不支持。
- ZIP/TAR/GZ/BZ2/XZ：列表、条目选择和解压。
- 7z：通过随项目保存的 `native/7za/7za.exe` 完成列表和解压。
- 冲突策略：覆盖、跳过、自动重命名、逐个询问。
- 基础安全：按文件头优先识别格式；拒绝绝对路径、盘符路径和 `..` 路径穿越；符号链接不写出；限制最大条目数、单文件/总展开大小和压缩比，解压前检查目标磁盘空间。
- 普通格式以 64KB 分块写入同目录临时文件，完成后改名；覆盖现有文件时通过 Windows `ReplaceFileW` 原子替换。进度显示当前文件、比例、写入量和速度，取消后关闭句柄并清理半成品。
- 7z 在条目路径预检后解压到隔离暂存目录，再按冲突策略移动到目标目录；支持终止外部进程并清理暂存目录。
- 创建入口支持 ZIP、TAR、TAR.GZ，可选择多个文件或整个目录；目录遍历不跟随链接，保留相对结构并限制条目数和总输入大小。
- 自动测试覆盖常用格式、路径安全、冲突策略以及 7z 创建夹具后的列表/解压闭环。

### 4.2 部分实现或未实现

- RAR、ISO 和 ZST 未实现列表/解压；RAR 需要 unrar 或完整 7-Zip，ISO 需要完整 7-Zip/libarchive 能力。
- 创建 7z 尚未实现；创建任务仍整体读取输入到内存，尚无进度和取消。
- 普通压缩格式当前整体读入内存，不适合超大压缩包；7z 走外部进程。
- 普通格式已有完整字节进度；随项目保存的旧版 7za 9.20 不支持 `-bsp` 百分比输出，因此外部进程阶段显示不确定进度，文件移入目标阶段显示确定进度。
- 加密包、损坏包、压缩炸弹、10 万条目和 500MB 包尚未形成完整自动+实机证据。
- 7z 中途终止外部进程仍缺大型压缩包自动夹具；当前自动测试覆盖预取消、暂存解压和清理闭环。

## 5. T2 Windows 清理

### 5.1 已实现

- 扫描 `%TEMP%`、Windows 临时目录、Edge/Chrome/Firefox、DirectX、错误报告、VS Code/Discord、npm/pnpm/Yarn/pip/Pub/Gradle/NuGet/Maven/Cargo/Go/Android 缓存和用户崩溃转储；扫描器不跟随链接并限制深度/数量。
- 扫描范围对话框默认启用用户临时文件、浏览器缓存和崩溃转储；Windows 临时目录作为高风险范围默认关闭，用户选择会持久化且不允许保存空范围。浏览器缓存/转储默认勾选，用户临时文件仅默认勾选超过 24 小时的项目。
- 下载目录只建议未完成下载和超过 30 天的安装包/压缩包；VS Code 旧插件只在同一插件存在更高版本时建议，二者均默认不选。
- 按类别折叠展示候选项、实际来源、完整路径、大小、修改时间与删除原因；万级结果按大小排序并分批渲染。
- 支持目录白名单的规范化、大小写无关去重、路径边界匹配、增删管理和设置文件持久化；扫描结果与最终清理计划都会重新应用白名单。
- 清理前显示确认对话框，普通清理通过 Windows `SHFileOperationW` 移入回收站；可再生成缓存可显式启用永久删除兜底，并清除只读属性后重试。
- 扫描显示当前路径、已检查数量、候选数量与累计大小，支持协作式取消；取消前后的扫描均不删除内容，并保留已发现候选。
- 清理按不可变候选快照逐项复核大小、修改时间和类型；分别记录成功、跳过、失败及实际释放字节，取消不计为失败。
- 清理完成生成 `%LOCALAPPDATA%\Vibekits\Reports\cleanup_<timestamp>.json`，报告不保存候选路径或文件内容；界面可查看汇总与非成功原因。
- 自动测试覆盖目标发现、下载/旧插件规则、万级结果分批显示、竞态复核和报告；生成夹具的真实回收站与强力删除均已通过。

### 5.2 部分实现或未实现

- 清理页的回收站容量、下载目录自动大文件/重复文件建议尚未实现；用户主动选择目录的重复文件扫描已在开发工具中完成。
- Visual Studio、JetBrains 插件清单和跳转卸载入口未实现；VS Code 当前只识别明确的旧版本残留。
- 占用与无权限会归入失败，文件在扫描后变化会跳过；Windows 清理快照已记录卷序列号和文件 ID，同路径被替换时即使大小/时间相同也会跳过。占用/无权限仍缺实机夹具验收。

## 6. T3 文档阅读

### 6.1 已实现

- 文本类：TXT、LOG、INI、CFG、CONF、PROPERTIES、YAML、YML、TOML、DIFF、PATCH、TEX、LATEX。
- Markdown：默认显示可读预览，源码可一键切换；预览使用单一滚动布局，窄工具栏保持核心按钮可操作。
- 结构化：CSV/TSV 表格、JSON/XML 可折叠树，解析失败时回退源码并提示。
- Web 文档：HTML/HTM、EPUB、SVG/SVGZ；HTML/EPUB 注入 CSP 并清理脚本/iframe，EPUB 有 DRM、路径穿越和解压规模检查。
- 二进制：BIN 的偏移、Hex、ASCII 三栏显示，Magic Number 和整数/浮点解释领域能力已有测试。
- 编码：UTF-8、UTF-16LE/BE、GBK、GB18030、Big5；Windows 代码页转换使用 `MultiByteToWideChar` FFI。
- 普通文本搜索、日志级别着色、自动换行、编码切换、文件信息和会话内最近文件。
- 大于 64MB 的文本使用 `FileLineIndex` 分块建立行索引并按行读取，不整文件载入内存。

### 6.2 部分实现或未实现

- 支持文件选择器、Windows 当前用户打开方式/默认应用、按格式区分文案的右键菜单，以及窗口拖拽/多启动参数逐项识别；压缩文件按文件头优先，模型进入模型仓库，未知文件按内容自动选文本或 Hex。运行中第二次外部进程通过 `WM_COPYDATA` 转发并激活既有窗口。
- 没有真正的多文档标签页；最近文件只保存在内存。
- 大文本流式模式禁用搜索；流式索引没有取消和关闭页面时的任务取消协议。
- Hex 仍整体读入内存，超过 256MB 直接拒绝；2GB 稀疏 BIN 和跨块搜索未实现。
- Hex 的选择、高亮、跳转偏移、大小端切换等完整 UI 操作未闭环。
- 未知扩展名会读取首 64KiB 自动选择文本或 Hex；当前尚未提供用户覆盖自动判断的持久偏好。
- 复制、保存导出、外链确认、本地图片、打印等行为尚未完成或未统一验收。
- 1GB 日志内存/首屏性能、25 个后缀实机路由、危险 Web 样本网络隔离仍缺正式人工证据。

### 7.2 部分实现或未实现

- 文件哈希主路径已闭环；尚未支持生成/校验 `.md5`、`.sha256` 清单文件，也未直接接管全局拖入文件。
- 没有收藏、最近使用、执行历史、多个工作区或参数模板。
- 网络状态标识、任务取消、敏感参数日志检查和正式 UI 验收未完成。

## 8. T5 本地模型

### 8.1 已实现

- 默认模型目录：`%LOCALAPPDATA%\Vibekits\Models`。
- 导入本地 ONNX/BIN/GGUF/MODEL 等文件、列出模型、按文件名推断 OCR/ASR/TTS 类别、删除模型。
- 强制单模型 100MB 上限；通过 `.part` 临时文件导入并流式计算 SHA-256，成功后记录本地清单。
- 每次列出模型会重新流式计算 SHA-256，与清单中的大小和哈希比较；界面区分“校验通过、文件已变化、未登记”，损坏清单安全降级为未登记。
- 精选清单包含固定来源、版本、许可证、大小和 SHA-256；下载由用户明确触发，显示进度、可取消，哈希错误不会安装。
- `sherpa-onnx 1.13.5`/ONNX Runtime Windows x64 CPU 运行时已接入。Silero VAD Sherpa 兼容版（629KB）和 v6（2.22MB）都用官方中文 WAV 通过真实离线推理。
- 语音片段检测工作区支持选择 16kHz WAV，输出片段起止/时长、总人声时长、耗时和运行时版本；推理在后台 Isolate 执行，不上传输入。
- `.onnx/.ort/.tflite/.gguf/.model` 拖入后自动进入模型仓库校验和导入。

### 8.2 未实现

- OCR、ASR、TTS 仍未接入，界面不展示不能运行的入口；当前实际推理能力是 VAD。
- 模型下载支持进度和取消但不支持断点续传；下载中断会删除临时文件。
- VAD 当前固定单线程 CPU，尚无阈值/线程高级设置、推理中强制取消和显式会话内存对比；会话在单次任务结束时释放。
- 通用 ONNX 张量探测尚未实现；只有两款清单内 Silero 模型完成兼容验证。

| P1 | 完成清理类别 | 回收站容量、下载大文件/重复文件、Visual Studio/JetBrains 插件建议 |
| P1 | 正式 Windows 验收 | 同一 Release Build 完成 62 项功能与 35 项 UI 证据，修正验收矩阵状态 |
| P2 | Windows 发布 | 安装器、签名、升级、许可证和发布校验值 |
| P2 | Android 平板 | 创建 Android 工程，替换平台专属能力，完成平板布局与 APK 验收 |

## 12. 结论

项目不是空骨架：Windows 五个 Tab 均已有代码，其中开发工具和文档阅读具备较多可用能力，压缩与清理主路径也已有进度、取消、安全复核和报告闭环，模型模块已完成可信下载、导入、校验和 VAD 真实离线推理。但按产品规格的严格完成定义，**当前尚不能标记 Windows V1 全部完成，更不能标记跨平台完成**。下一阶段应扩展 OCR 等第二类模型能力，补齐剩余格式和系统入口，再进入正式验收与 Android 适配。
