# Vibekits 交互与操作习惯规范（Windows 基线）

版本：0.1
状态：交互设计基线
原则：**每个界面必须对标一个主流参考应用，复用其既有操作习惯，不自行发明交互。**

最高约束：以 [统一产品需求](00_PRODUCT_REQUIREMENTS.md) 的操作预算为准。默认自动选择最佳能力，每个工作区只保留一个主操作，高级参数按需展开，结果可一键交给下一工具。macOS 使用等价的 Command 快捷键、菜单栏、Finder 和废纸篓习惯。

任何新增交互若无法对应到“某款主流应用就是这么做的”，需要先在本文件登记并在需求确认后才可实施。

## 1. 参考应用对照

| 模块 | 主参考 | 辅助参考 | 吸收要点 |
|---|---|---|---|
| 应用外壳 | 360 安全卫士 | 现代 Windows 设置 | 顶部大 Tab、状态栏、一键式主操作 |
| T1 解压缩 | 7-Zip | WinRAR、Bandizip | 工具栏、右键菜单、解压/创建对话框、冲突处理 |
| T2 Windows 清理 | 360 安全卫士 / CCleaner | Windows 磁盘清理 | 扫描→分类勾选→清理→报告四步 |
| T3 文档阅读 | Notepad++ / VS Code | Typora、010 Editor、浏览器 | 多标签、查找替换、折叠树、Hex 三栏 |
| T4 开发工具 | DevToys | CyberChef、IT-Tools | 分组导航、输入/输出双栏、一键复制 |
| T5 本地模型 | 下载管理器 / Ollama | 语音识别桌面工具 | 列表+进度下载、加载/释放、运行/取消 |
| 全文件融合 | Windows 打开方式 / macOS Finder | Raycast、DevToys | 拖入即识别、一个主动作、结果就地继续处理 |

## 2. 全局交互约定（Windows 桌面共性）

### 2.1 键盘

以下快捷键与主流 Windows 应用一致，不得改变语义：

| 快捷键 | 动作 | 参考来源 |
|---|---|---|
| `Ctrl+O` | 打开文件/压缩包 | 几乎所有桌面应用 |
| `Ctrl+S` | 保存当前输出/文档 | 通用 |
| `Ctrl+F` | 查找（当前页） | 通用 |
| `Ctrl+G` | 转到行/偏移 | Notepad++ / 010 Editor |
| `Ctrl+A` | 全选 | 通用 |
| `Ctrl+C/X/V` | 复制/剪切/粘贴 | 通用 |
| `Ctrl+Z/Y` | 撤销/重做（文本输入） | 通用 |
| `Ctrl+W` | 关闭当前标签页 | 浏览器 / VS Code |
| `Ctrl+Tab` | 切换标签页 | 浏览器 |
| `F5` | 刷新/重新扫描 | 浏览器 / 360 |
| `Delete` | 删除所选（危险项需确认） | 通用 |
| `Ctrl+1`～`Ctrl+5` | 切换一级 Tab | 本应用导航 |
| `Ctrl+,` | 设置 | VS Code |
| `Enter` | 执行当前默认非危险操作 | 通用 |
| `Esc` | 关闭弹层 / 取消 | 通用 |

### 2.2 鼠标

- 单选：单击；连选：`Shift+单击`；跳选：`Ctrl+单击`。
- 双击文件 = 打开（文本、压缩包、图片）；双击文件夹 = 进入。
- 右键 = 上下文菜单，菜单项与对应参考应用一致。
- 列表列头可点击排序，再次点击反向；拖拽列头边界调整列宽。
- 拖放：文件拖入窗口 = 打开；条目从窗口拖出 = 导出（后续里程碑按需）。

### 2.3 对话框风格

- 使用 Windows 原生式对话框布局：标题、说明文字、输入区、确定/取消（确定在右下）。
- 危险操作默认焦点在“取消”，`Enter` 不得直接触发永久删除或覆盖。
- 文件打开/保存使用系统标准对话框（`file_selector`），不自定义文件浏览器。

### 2.4 状态与进度

- 进度条 + 当前项文本 + 百分比 + 速度（IO 类）或“处理中…”（计算类），不确定时显示动画但必须可取消。
- 所有长任务可“最小化到后台”，主窗口不阻塞；后台任务入口常驻右上角（360 风格）。

## 3. T1 解压缩（对标 7-Zip / WinRAR）

### 3.1 主界面

```
┌ 工具栏：打开 | 解压 | 新建压缩包 | 测试 | 删除 | 信息 ────────┐
├ 地址栏 / 包内路径导航（面包屑）                                ─┤
├ 文件列表：名称 | 大小(解压) | 压缩后 | 类型 | 修改时间          ─┤
├ 状态栏：N 个对象，已选 M 个，X 字节                            ─┤
└──────────────────────────────────────────────┘
```

- 双击压缩包文件 → 在应用内打开并显示条目（7-Zip 行为）。
- 双击包内文件夹 → 进入该目录；双击文件 → 只读预览。
- 右键菜单（与 7-Zip 一致）：

```text
打开
用 Vibekits 打开
────────────────
解压到当前文件夹...
解压到 "名称\"...
────────────────
添加到压缩包...
────────────────
测试压缩包
────────────────
属性
```

- 选择条目后点“解压”= 只解压所选；未选择时 = 解压全部。

### 3.2 解压对话框（仿 7-Zip）

```
目标路径        [可编辑文本框 + 浏览...]        （默认：当前压缩包同目录）
路径模式        （解压到根目录 / 保留完整路径）
覆盖模式        （询问 / 覆盖 / 跳过 / 自动重命名）   ← WinRAR 风格四选一
密码            [____显示/隐藏____]（仅在需要时出现）
选项            [x] 完成后打开目标文件夹
                [x] 保持目录结构
                [解压] [取消]
```

### 3.3 创建压缩包对话框（仿 7-Zip）

```
来源（列表，可增删/拖入）
压缩格式        [下拉：7z / zip / tar / tar.gz]
压缩级别        [下拉：仅存储/最快/快速/正常/最大/极限]
压缩方法        （格式相关：Deflate/LZMA2/…）
分卷大小        [下拉：不限 / 常见档位]
密码            [____显示/隐藏____]（zip 支持；不记录）
更新模式        （添加并替换 / 更新 / 同步）
                [确定] [取消]
```

### 3.4 冲突与进度

- 文件已存在 → 仿 WinRAR 冲突对话框：目标、大小、时间对比 + 覆盖/跳过/重命名/全部应用。
- 进度窗：当前文件、总进度、已写字节、速度、剩余时间、取消、后台。
- 加密包：先列目录；需要密码解压时才弹密码，不用密码就不打扰。

## 4. T2 Windows 清理（对标 360 / CCleaner）

### 4.1 流程

```text
首页（范围说明 + [开始扫描]）
  → 扫描中（分类实时累计，可取消，不删除任何东西）
  → 结果（分类列表，勾选 + 大小 + 风险）
  → 确认（分组：移入回收站 / 永久删除，永久需二次勾选）
  → 清理进度 → 完成页（成功/跳过/失败/实际释放 + [查看报告]）
```

### 4.2 结果页交互（CCleaner 风格）

- 每个分类一行：复选框 + 图标 + 名称 + 项数 + 大小；复选框三态（全选/部分/未选）。
- 点击分类行展开到单个文件，可逐项取消；再次点击收起。
- 顶部：全选 / 反选 / 筛选（全部、安全、需确认、高风险建议）。
- 底部固定：已选择大小合计 + `[清理 N 项]`。
- 下载目录与插件只在“建议”区，默认不勾选，不混入垃圾项。

### 4.3 白名单

- 结果项右键 → `加入白名单`（CCleaner 排除项习惯）。
- 白名单管理页：列表 + 移除，按路径去重。

## 5. T3 文档阅读（对标 Notepad++ / VS Code / 010 Editor）

### 5.1 多文档

- 顶部标签页，`Ctrl+Tab` 切换、`Ctrl+W` 关闭、`Ctrl+O` 打开（VS Code 习惯）。
- 左侧可选“打开文件 / 最近文件”列表（Notepad++ 会话习惯）。

### 5.2 文本/日志/配置

- 行号、换行开关、编码下拉（右下角，Notepad++ 习惯）。
- 查找栏 `Ctrl+F`：查找/上一个/下一个/匹配数/高亮（Notepad++）。
- 转到行 `Ctrl+G`。
- 状态栏：行:列、编码、格式（右下角）。
- 日志着色：ERROR/WARN/INFO/DEBUG 着色（VS Code 输出面板习惯）。

### 5.3 Markdown

- 右上“预览 / 源码”切换（Typora 双模式），预览只读、源码可复制。
- 保留大纲切换（后续）。

### 5.4 CSV/TSV

- Excel 风格：冻结表头、可调列宽、点击列头排序、横向滚动。
- 分隔符可切换（逗号/制表符/自定义）。

### 5.5 JSON / XML

- VS Code / DevToys 风格：可折叠树、缩进、语法着色；工具栏 `[格式化] [压缩] [全部折叠] [全部展开]`。
- 解析失败 → 自动切到源码视图并标出错误行/位置（VS Code 习惯）。

### 5.6 HTML / EPUB / SVG

- 浏览器阅读习惯：滚动、缩放（`Ctrl+滚轮`）、链接点击需确认后交默认浏览器。

### 5.7 二进制（对标 010 Editor / HxD）

```
偏移(hex/dec) | 十六进制字节（8/16/32 每行） | ASCII
```

- `Ctrl+G` 跳转偏移、`Ctrl+F` 搜索字节序列/文本、大小端切换。
- 选中字节在 Hex 与 ASCII 双侧同步高亮，底部解释整数/浮点（010 Editor 习惯）。
- 右侧信息栏显示 Magic Number 识别提示（仅提示，不跳解析器）。

## 6. T4 开发工具（对标 DevToys）

### 6.1 导航

- 左侧分组列表 + 顶部搜索（DevToys 习惯），工具图标+名称；最近使用与收藏置顶。
- 双击工具 = 打开到右侧工作区；右侧同时只保留一个工具工作区（DevToys 单工作区习惯）。

### 6.2 工作区布局（DevToys 风格）

```
工具名         [自动执行开关] [收藏] [帮助]
─────────────────────────────
参数栏（仅当工具需要参数）
输入  [多行输入框 / 文件拖放区]
      [执行] [交换] [清空]
输出  [只读输出框]
      [复制] [保存] [另存]
```

- `复制` = 输出区右下角小按钮（DevToys 习惯，一键复制结果）。
- 编码类工具支持“自动执行”（输入即出结果），计算类保持显式执行。
- 文件型输入（哈希、重命名）将输入框替换为文件拖放区 + 文件表（DevToys 文件工具习惯）。

### 6.3 错误

- 错误就地显示在输出区顶部（红色横幅 + 原因 + 位置），不清空输入（DevToys 习惯）。

## 7. T5 本地模型（对标下载管理器 / Ollama）

### 7.1 模型管理

- 左侧列表：名称、能力标签、大小、状态（未安装/下载中 xx%/可用/校验失败/已加载）。
- 选中项右侧显示详情：许可证、来源、SHA-256、安装路径、`[删除]`。
- 下载即下载管理器风格：进度条 + 速度 + 剩余时间 + 取消 + 失败重试（浏览器下载习惯）。

### 7.2 工作区

```
[OCR | ASR | TTS]  切换输入控件（Tab 内分段控件，类似语音工具）
输入区（图片拖放 / 音频选择或录音 / 文本）
[运行] [取消] [释放模型]
结果区（文本/时间戳/播放器）+ [复制] [保存]
```

- 状态栏显示模型内存占用；释放后显示前后对比，不承诺清理其他进程。

## 8. 交付口径

实现每个页面时，代码评审必须能回答“这对应哪款主流应用的哪个操作”。无法回答的交互视为违反本规范，退回重做。

本文档与 [01_WINDOWS_UI_LAYOUT.md](01_WINDOWS_UI_LAYOUT.md) 冲突时，以本文档的操作习惯为准；视觉尺寸仍以 01 为准。
